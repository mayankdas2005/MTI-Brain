# assets/

Static assets for the MTI Brain project — primarily visual references for the LangGraph analytics pipeline.

## Contents

### `analytics_graph.mmd`

Mermaid source for the full LangGraph analytics pipeline DAG. This is the **authoritative visual reference** for the node graph — it is generated directly from the compiled LangGraph graph and reflects every node and routing edge in the production pipeline.

Key nodes visible in the diagram:

| Stage | Nodes |
|-------|-------|
| Routing | `intake_classifier` → `general_chat` or analytics path |
| Context | `context_fetcher` → `tribal_retrieval` → `anchor_resolver` |
| Planning | `query_planner` → `schema_enricher` |
| Intent | `measure_specialist`, `filter_specialist`, `dimension_specialist` (parallel) → `intent_assembler` |
| Directive | `directive_writer` → `schema_gap_resolver` |
| Query | `query_compiler` → [`filter_resolver` →] `sql_generator` |
| Validation | `sql_validator` |
| Execution | `executor` |
| Quality | `data_quality_checker` → `synthesis` |
| Output | `chart_agent`, `compress` |
| Error | `error_response`, `intent_resolver` (fallback) |

---

### `analytics_graph.png`

Pre-rendered PNG of `analytics_graph.mmd` for quick reference without a Mermaid renderer.

---

## Regenerating the PNG

The diagram is generated by the backend's `render_graph.py` script, which compiles the live LangGraph graph and exports it as both Mermaid and PNG.

```bash
cd backend
python scripts/render_graph.py
# Writes analytics_graph.mmd and analytics_graph.png to ../assets/
```

Alternatively, regenerate the PNG directly from the Mermaid source using the Mermaid CLI:

```bash
# Install once
npm install -g @mermaid-js/mermaid-cli

# Render
mmdc -i assets/analytics_graph.mmd -o assets/analytics_graph.png
```

**Keep in sync:** whenever a node is added to or removed from `backend/app/services/agents/graph.py`, re-run `render_graph.py` and commit the updated `analytics_graph.mmd` and `analytics_graph.png`.
