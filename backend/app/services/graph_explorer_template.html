How to use
Click node / edge Select it & view properties in the side panel
Double-click node Expand or collapse its connected children
Drag node Reposition the node freely
Right-click node Context menu: Expand / Collapse / Dismiss
Scroll wheel Zoom in / out
Drag canvas Pan the view
Search box Filter nodes by name (others are dimmed)
Fit button Reset camera to show all nodes
Collapse All button Hide all expanded children
Auto Layout button Force-directed auto-arrange — animates nodes to optimal positions
